# 🎄 Advent of Code 2025 🎄

Welcome to my solutions repository for **[Advent of Code 2025](https://adventofcode.com/2025)**!

This space is dedicated to documenting my journey through the daily programming challenges. The goal is to solve the puzzles, possibly learn new concepts, and have fun!

---

## 🛠️ Language and Tools

The solutions in this repository are written in **TypeScript**.

Any specific libraries or tools used will be mentioned in the individual day folders if necessary.

## 📁 Repository Structure

The repository is organized by day. Each puzzle has a dedicated folder:

```
├── Day01/
    ├── day01.js       # Code for Part 1 and Part 2
    └── README.md        # (Optional) Notes or thoughts on the puzzle

├── Day02/
    ├── day02.js
    └── ...

├── ...

└── Day12/
```
